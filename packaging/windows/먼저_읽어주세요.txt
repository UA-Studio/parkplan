지하주차장 배치 v{VERSION} ({DATE}) - Windows 설치 없는 버전

필요한 것: 64비트 Windows 10 또는 11. 파이썬이나 다른 프로그램을 따로 설치하지 않아도 됩니다.

1. zip 파일을 오른쪽 클릭 → "모두 압축 풀기"로 푼 뒤, 풀린 폴더에서 실행하세요 (zip 안에서 바로 실행하면 안 됩니다).
2. "지하주차장 실행.bat"을 더블클릭합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면: 추가 정보 → 실행
3. 브라우저에 화면이 열립니다. DXF 또는 3dm 도면을 끌어다 놓고(또는 "예시 도면으로 해보기"), 레이어 역할을 확인한 뒤 "배치 찾기".
4. 결과는 C:\Users\내이름\지하주차장 폴더에 저장됩니다 (화면의 "결과 폴더 열기").

폴더(지하주차장_윈도우)를 통째로 복사하면 다른 컴퓨터에서도 그대로 실행됩니다. 안의 python 폴더는 지우거나 옮기지 마세요.
검은 창을 닫으면 프로그램이 꺼집니다. 자세한 설명은 사용법_전체.md, 예시 도면은 예시 폴더에 있습니다.
