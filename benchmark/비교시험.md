# 같은 대지 비교 시험 (ARCHITEChTURES · PRKNG_sqr)

같은 대지를 다른 자동 배치 도구에 넣고 대수와 시간을 비교해 우리 프로그램의 수준을 확인합니다.
회원 가입이나 라이노가 필요해서 다른 도구는 직접 돌려야 합니다. 우리 쪽 결과는 [우리_결과.md](우리_결과.md)에 미리 넣어 두었습니다.

## 1. 시험 대지 (이 폴더의 DXF, 합성 대지)

| 파일 | 내용 | 레이어 |
|---|---|---|
| `B0_rect.dxf` | 직사각형 60×40m, 코어·경사로 없음. 모든 도구가 다룰 수 있음 | SITE |
| `B1_sample.dxf` | 꺾인 대지 약 3,600㎡, 코어 2, 직선 경사로 1 | SITE · CORE · RAMP |
| `B2_big.dxf` | 큰 대지 약 9,900㎡, 코어 3, 경사로 1 | SITE · CORE · RAMP |

단위는 mm입니다. 다시 만들려면 `python benchmark/make_sites.py`를 실행합니다.

## 2. 조건 맞추기 (모든 도구 공통)

- 지하 1개 층, 직각(90°) 주차
- 구획 2.5×5.0m, 차로 6.0m
- 우리 프로그램은 법규대로 확장형 2.6×5.2를 30% 넣습니다. 다른 도구가 확장형을 못 넣으면 '8.1m 격자·기둥600·확장형 없음' 줄과 비교하세요.
- 기둥: 도구가 정하는 값을 그대로 쓰되, 표에 기둥 크기와 간격을 적습니다.
- 경사로는 그린 위치에 고정합니다. 도구가 경사로를 못 그리면 그 영역을 장애물로 넣습니다.

## 3. 도구별 절차

### ARCHITEChTURES (웹, 무료 체험)
1. https://architechtures.com 에서 무료 체험 가입 → 새 프로젝트
2. 대지 DXF를 가져와 SITE 레이어를 지하층 경계(basement)로 지정
3. 지하 1층, 주차 2.5×5.0, 차로 6.0, 기둥 간격과 크기를 입력하고 'Auto' 모드로 생성
4. 경사로: RAMP 위치에 맞춰 access ramp를 직접 그림(이 도구는 경사로를 사용자가 그려야 함)
5. 주차 대수, 생성 시간, 화면 캡처를 기록

### PRKNG_sqr (라이노 그라스호퍼, 무료)
1. food4rhino에서 PRKNG_sqr를 설치(한국어 설명서 있음)
2. 라이노에서 DXF를 열고 SITE 곡선을 경계로 연결
3. 기본 격자 8.1m, 기둥 600, 구획 2.5×5.0, 차로 6.0
4. 코어·경사로를 제외 영역으로 넣을 수 있으면 넣고, 아니면 B0_rect만 비교
5. 주차 대수와 화면 캡처를 기록
